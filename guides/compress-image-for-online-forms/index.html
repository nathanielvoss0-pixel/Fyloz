PRACTICAL IMAGE GUIDE

How to compress a photo for an online form.

When an application portal says “maximum 50 KB” or “maximum 100 KB,” the file must meet the size limit and any separate requirements for dimensions and format. Use this checklist before uploading.

Open the image compressor ↗

1. Check the exact requirements first

Look at the instructions beside the upload field. A maximum file size is not the same as an image-dimension requirement: a portal may ask for both, such as a 100 KB limit and a specific width and height.

  • File size: note whether the limit is 50 KB, 100 KB, or another value.
  • Dimensions: check whether the portal specifies pixels, such as 600 × 600.
  • Format: confirm whether JPG/JPEG, PNG, or another format is accepted.
  • Photo rules: follow the portal's requirements for background, cropping, and image content.

2. Reduce the image to 50 KB or 100 KB

  1. Open the Fyloz image compressor.
  2. Select the photo from your device.
  3. Enter the required maximum size, or choose the 50 KB or 100 KB preset.
  4. Select Prepare image, then inspect the preview and output size.
  5. Download the JPEG only if it remains clear enough for the form.

The compressor processes the image in your browser. It creates a JPEG copy, so transparent areas in a PNG or WebP image become white. Keep your original file in case you need another format.

3. If the photo looks blurry

Very small file limits can force a trade-off between file size and detail. Try these steps in order:

  1. Start with a clear original photo rather than a screenshot or an image that has already been compressed several times.
  2. If the portal permits it, try a slightly larger file-size limit.
  3. If the portal specifies pixel dimensions, use the image resizer to set them correctly, then check the file size again.
  4. Do not keep reducing dimensions if the form requires a minimum resolution.

4. Common upload problems

The file is small enough, but the portal rejects it

Check the required format, dimensions, filename rules, and any minimum-size requirement. Meeting the KB limit alone may not be enough.

The photo is under 50 KB but hard to read

Use a better original and avoid shrinking the dimensions more than necessary. If the portal allows 100 KB, try that instead.

Can I use the same photo for every application?

Not always. Different portals may require different dimensions, formats, backgrounds, or file-size limits. Check each portal's instructions separately.

Does compression change the original?

Fyloz provides a compressed download; keep your original file separately so you can try different settings later.

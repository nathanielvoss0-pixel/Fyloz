UPLOAD TROUBLESHOOTING

Why is my image rejected by an online form?

A photo can be below the stated KB limit and still fail to upload. The form may also check its format, pixel dimensions, filename, or content. Use this checklist before trying again.

Compress an image with Fyloz ↗

1. Check the file size

Read the maximum size shown beside the upload field. If the limit is 100 KB, a file of 105 KB is too large. Leaving a small margin can help with portals that behave inconsistently near the limit. Use the Fyloz compressor to create a smaller copy, then check its output size.

2. Confirm the format

Some portals accept JPG/JPEG only, while others accept PNG. Renaming a .WEBP or .HEIC file to .JPG does not convert it. Create a real JPEG copy if the form requires JPG, and keep the original in case you need another format.

Open the image converter ↗

3. Check pixel dimensions

File size and image dimensions are different. A portal may require a square photo or exact dimensions such as 600 × 600 pixels. Compression alone does not meet that requirement. Read the portal instructions and use the image resizer if exact pixel dimensions are required.

4. Try a simpler filename

Try a short filename such as photo01.jpg. Avoid unusual symbols, very long names, and multiple dots. This is a troubleshooting step, not a universal requirement; follow the portal's own instructions when provided.

5. Check the photo rules

Some applications check the photo itself: background, crop, face visibility, or filters. Follow the official requirements for that application. A smaller file cannot fix a photo that fails content rules.

6. If it still fails

Open the saved file

Make sure the downloaded image opens correctly and is not damaged.

Save a fresh copy

Use a new filename rather than repeatedly overwriting the same file.

Try another browser

If the file meets all requirements, refresh the page or try a current browser; the portal may have a temporary issue.

Read the exact error

“Unsupported format,” “invalid dimensions,” and “file too large” require different fixes.

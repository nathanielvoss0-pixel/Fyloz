الأسئلة الشائعة

أسئلة حول أدوات PDF

هل تُرفع مستنداتي؟

لا. تعالج الأدوات ملفاتك في المتصفح. تُحمّل نصوص المكتبات الخارجية من شبكات عامة، لكن هذه الأدوات لا ترسل ملفات المستندات إليها.

هل يؤدي تحسين PDF دائماً إلى ملف أصغر؟

لا. قد تقلل إعادة الحفظ بعض البيانات الهيكلية الزائدة، لكن حجم الملف قد يبقى كما هو أو يزيد. ولا تضمن إعادة ضغط الصور.

هل يمكنني تقسيم PDF إلى عدة ملفات؟

نعم. اختر «تقسيم حسب نطاق الصفحات» وأدخل النطاقات مفصولة بفواصل منقوطة، مثل 1-3؛ 4-6؛ 7-9.

هل تعمل الأداة مع كل ملفات PDF؟

قد لا تدعم الأداة بعض ملفات PDF المشفرة أو التالفة أو المعقدة جداً أو الكبيرة. إذا فشل الملف، جرّب قارئ PDF آخر أو صدّر نسخة جديدة.

كيف أحول PDF إلى JPG أو PNG؟

اختر «PDF إلى JPG أو PNG»، وحدد ملفك والصيغة ثم عالج الملف. تُصدّر كل صفحة كصورة قابلة للتنزيل.

هل يمكن دمج ملفات PDF مجاناً عبر الإنترنت؟

نعم. اختر «دمج ملفات PDF»، وحدد ملفين أو أكثر، ثم عالجهما لإنشاء ملف PDF واحد. تتم المعالجة في متصفحك.

GUIDE PRATIQUE DES IMAGES

Comment compresser une photo pour un formulaire en ligne.

Lorsqu’un portail de candidature impose 50 ou 100 Ko maximum, le fichier doit respecter cette limite ainsi que les exigences de dimensions et de format. Suivez cette liste avant le téléversement.

Ouvrir le compresseur d’images ↗

1. Vérifiez d’abord les exigences exactes

Lisez les instructions près du champ de téléversement. Une taille maximale ne remplace pas les dimensions : le portail peut demander les deux, par exemple 100 Ko et une largeur et hauteur précises.

  • Taille du fichier : notez si la limite est de 50 Ko, 100 Ko ou d’une autre valeur.
  • Dimensions : vérifiez si le portail impose des pixels, par exemple 600 × 600.
  • Format : confirmez si JPG/JPEG, PNG ou un autre format est accepté.
  • Règles photo : suivez les exigences du portail concernant le fond, le cadrage et le contenu.

2. Réduisez l’image à 50 ou 100 Ko

  1. Ouvrez le compresseur d’images Fyloz.
  2. Sélectionnez la photo sur votre appareil.
  3. Saisissez la taille maximale requise ou choisissez 50 Ko ou 100 Ko.
  4. Sélectionnez Préparer l’image, puis vérifiez l’aperçu et la taille obtenue.
  5. Téléchargez le JPEG uniquement s’il reste assez net pour le formulaire.

Le compresseur traite l’image dans votre navigateur et crée une copie JPEG ; les zones transparentes d’une image PNG ou WebP deviennent donc blanches. Gardez l’original si vous avez besoin d’un autre format.

Compresser une image maintenant ↗

3. Si la photo semble floue

Une limite très basse peut imposer un compromis entre le poids et les détails. Essayez ces étapes dans l’ordre :

  1. Commencez par une photo originale nette plutôt qu’une capture d’écran ou une image déjà compressée plusieurs fois.
  2. Si le portail l’autorise, essayez une limite de taille légèrement supérieure.
  3. Si le portail impose des dimensions en pixels, utilisez l’outil de redimensionnement pour les régler, puis vérifiez à nouveau le poids du fichier.
  4. Ne réduisez pas davantage les dimensions si le formulaire impose une résolution minimale.

4. Problèmes fréquents de téléversement

Le fichier est assez léger, mais le portail le refuse

Vérifiez le format, les dimensions, le nom du fichier et toute taille minimale. Respecter la limite en Ko peut ne pas suffire.

La photo fait moins de 50 Ko mais reste difficile à lire

Utilisez un meilleur original et évitez de réduire les dimensions plus que nécessaire. Si le portail accepte 100 Ko, essayez cette limite.

Puis-je utiliser la même photo pour chaque candidature ?

Pas toujours. Les portails peuvent exiger des dimensions, formats, fonds ou tailles différentes. Vérifiez chaque consigne séparément.

La compression modifie-t-elle l’original ?

Fyloz fournit une copie compressée à télécharger ; gardez l’original pour essayer d’autres réglages.

GOOD TO KNOW

Image format FAQs

Does my image leave my device?

No. The browser converts the image locally; it is not uploaded to the Fyloz application server.

Which format should I use?

JPG is widely compatible for photos, PNG supports transparency, and WebP is designed for efficient web images. The best choice depends on the destination.

Will conversion reduce quality?

JPG and WebP are lossy formats when exported with lossy quality settings. PNG is lossless, but the output file may be larger.

Can JPG keep transparent areas?

No. When converting a transparent image to JPG, Fyloz fills transparent areas with white.

PICK THE RIGHT FORMAT

JPG vs PNG vs WebP

JPG

Photos and everyday sharing

Good compatibility and adjustable quality. It does not preserve transparency.

PNG

Transparent graphics

Preserves transparency and image data, but can create larger files for photographs.

WEBP

Modern websites

Often offers efficient file sizes. Check that the app or website you use supports WebP.
